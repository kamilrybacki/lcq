# Claude Code entry point

Read and follow `AGENTS.md` and `docs/HANDOFF.md` before taking implementation actions.

This repository contains a design and implementation handoff, not an implemented protocol. Begin with the bounded M1 plan identified in the handoff after the user approves execution. Do not start all milestones in parallel. In particular, do not build a Morsik-specific MQTT service inside the reusable `lorai` core.

Use the supplied specs as the source of product decisions. Treat engineering proposals as proposals. When continuing, report which milestone you are executing, run actual verification, and update the handoff so another session can resume without the original conversation.
